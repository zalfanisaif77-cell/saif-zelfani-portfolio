Publication :
1. Dezippez l’archive. Ouvrez le dossier contenant index.html.
2. Copiez son contenu à la RACINE du depot GitHub existant, pas le ZIP lui-meme.
3. Ne supprimez pas le repertoire .git quand vous travaillez avec une copie locale du depot.
4. Commit et push sur la branche main. GitHub Pages redeploiera automatiquement.
5. Verifiez les pages projet, les fleches du carrousel et le bouton CV.

Aucun document strategique interne ou video lourde n'a ete publie automatiquement.
Les contenus de conseil de sante sont des demonstrations graphiques, pas un avis medical.
Les offres de produits visibles dans les originaux sont historiques, pas des prix actuels.

Contact : le formulaire ouvre votre logiciel email; il n'envoie pas automatiquement.
